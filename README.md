# CampusPay

### Smart Personal Finance Management for Students

CampusPay is a student-focused personal finance management platform designed to help college students **track expenses, manage savings goals, split group expenses, discover student discounts, and receive personalized financial insights** — all in one place.

The project combines a **Flask backend, MySQL database, HTML/CSS/JavaScript frontend, and AI-powered financial assistance** to provide students with a practical and centralized approach to managing their money.

---

## 🚀 Features

### 🔐 User Authentication

* Secure user registration and login
* Session-based authentication
* User profile management
* College information and monthly budget support
* Logout functionality

### 💰 Expense Management

* Add personal expenses
* View expense history
* Update existing expenses
* Delete expenses
* Calculate total spending and expense summaries
* Categorize expenses for better financial tracking

### 🎯 Savings Goals

* Create personalized savings goals
* Set target amounts and target dates
* Track current savings
* Record monthly contributions
* Calculate goal progress
* Calculate remaining amount
* Estimate the number of months required to reach a goal
* Update and delete savings goals

### 👥 Group Expense Management

* Create expense-sharing groups
* Add members to groups
* View group members
* View groups associated with a user
* Add group expenses
* Update and delete group expenses

### 🧮 SmartSplit

CampusPay provides multiple expense-splitting methods:

* Equal split
* Unequal split
* Percentage-based split
* Item-based split

This makes it easier for students to manage expenses during trips, meals, events, and shared purchases.

### 🎓 Student Discounts

* Browse available student discounts
* Filter discounts by category
* Calculate discount percentages
* Discover recommended discounts

### 📊 Financial Insights

CampusPay analyzes spending data to provide useful financial information, including:

* Total spending
* Average expense
* Category-wise spending
* Budget-related insights
* Personalized financial recommendations

### 🤖 AI Finance Assistant

The AI Finance module provides:

* Personalized financial insights
* Purchase advice based on available balance
* Financial assistance through a chat interface
* Spending-based recommendations
